# アプリごとのプロファイル

`profiles/` に `.yaml` ファイルを置くと、そのアプリが前面にあるときだけ有効な設定を追加できます。
変更後は voicectl を再起動してください。

```yaml
name: アプリの表示名

match:
  exe: [実行ファイル名の一部]      # 例: piosolver（小文字で照合）
  title: [ウィンドウタイトルの一部]

launch: C:\path\to\app.exe         # スタートメニューにないアプリの起動パス（任意）
readings: [読み, 読み]             # 「〇〇開いて」で起動するための読み（どのアプリが前面でも有効）

dictionary:                        # 前面のときだけ使う読み替え（読み: 表記）
  ジーティーオー: GTO

vocabulary:                        # 前面のときだけ足す音声認識のヒント
  - 専門用語

commands:                          # 独自コマンド
  コマンド名:
    say: [言い方1, 言い方2]
    confirm: false                 # true なら実行前に必ず確認
    do:
      - keys: "Ctrl+B"
      - menu: [メニュー, 項目]
      - click: "ボタン名"
      - text: "入力する文字"
      - wait: 0.5
```

## アプリマップ（メニューの自動読み取り）

アプリを前面にして「**このアプリを覚えて**」と言うと、メニューバーの中身とショートカットを読み取って
`cache/appmaps/<実行ファイル名>.json` に保存します。以後、そのアプリでは「名前を付けて保存して」のように
メニューの項目名で操作できます。アプリを更新してメニューが変わったら、もう一度「このアプリを覚えて」と言ってください。

- メニューバーのないアプリ（リボン UI、ゲーム、独自描画の画面など）は読み取れません。
  その場合は `commands` に手順を書くか、「番号表示」を使ってください。
- 「終了」「削除」「閉じる」などを含むメニューは、実行前に必ず確認します（`config.yaml` の `menu_confirm_words`）。

## 同梱のプロファイル

| ファイル | 対象 | 例（言い方の一部） |
|---|---|---|
| `youtube.yaml` | YouTube / ユーチューブ（ウィンドウタイトルで判定） | 再生と一時停止、早送り、全画面、シアターモード、字幕、次の動画、再生速度 |
| `notepad.yaml` | メモ帳 | 上書き保存、名前を付けて保存、折り返し、拡大・縮小、時刻と日付、行へ移動 |
| `explorer.yaml` | エクスプローラー | 新しいフォルダ、名前を変更、上の階層へ、新しいタブ、詳細表示、プロパティ、削除（確認あり） |
| `vlc.yaml` | VLC | 再生と一時停止、シーク、全画面、音量、ミュート、次のファイル、字幕、ループ |
| `vscode.yaml` | Visual Studio Code | コマンドパレット、ファイル移動、全体検索、置換、サイドバー、ターミナル、すべて保存、整形 |

`match` に `title` と `exe` の両方がある候補が競合したときは、**ウィンドウタイトルに一致した方**を優先します。
（例: Brave で YouTube を見ているときは、Brave ではなく `youtube.yaml` のショートカットが効きます）

## 注意

- `keys` に書くキーは、そのアプリの実際のショートカットと一致している必要があります。
  迷ったらアプリのヘルプや設定画面で確認してください（間違ったキーは別の操作を実行してしまいます）。
- コマンドパレット経由の操作（VS Code の「ターミナル」など）は `keys` → `text` → `keys` の順に並べます:
  ```yaml
  ターミナル:
    say: [ターミナル, ターミナル開いて]
    do:
      - keys: "Ctrl+Shift+P"
      - text: "Toggle Terminal"
      - keys: "Enter"
  ```
